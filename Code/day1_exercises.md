# Day 1 Gap Exercises

Complete these without looking at the solution first.

1. Write a program using comparison and logical operators.
2. Print numbers 1–20 but skip multiples of 3 using continue.
3. Stop a loop when the number reaches 10 using break.
4. Print a 5 x 5 star pattern using nested loops.
5. Create a tuple containing name, roll number and marks.
6. Remove duplicates from a list using a set.
7. Write a function that demonstrates local and global variables.
8. Sort students by marks using lambda.
9. Save a list of students to JSON and read it back.
10. Add Update and Delete features to Student Record Management.

Expected Day-1 outcome:
Python basics + collections + functions + exceptions + TXT/CSV/JSON + logic building + Git/GitHub + mini project.
